Personal Fantasy Football Draft Assistant

A locally hosted tool for helping its owner analyze the owner's own fantasy league and team information while preparing for a fantasy football draft.

Availability

This is a single-user, personal, non-commercial project. It is not offered as a public service and is not distributed through an app store.

Data use

The application is designed for authorized, read-only access. Private fantasy information and OAuth credentials remain local, are not sold or shared, and are not published with the source code.

Privacy

Development uses synthetic test information. Real fantasy information is not intentionally sent to external AI systems, analytics services, or advertising platforms.

The repository includes the complete privacy notice and security policy.

Fantasy data provided by Yahoo Fantasy.

This independent project is not affiliated with or endorsed by Yahoo.
